# Code of Conduct

## Our Pledge

We are committed to making participation in the LexFlow project a respectful and welcoming experience for everyone.

We expect all contributors and participants to:

- Be respectful and professional.
- Communicate constructively.
- Welcome different perspectives and experiences.
- Focus on what is best for the project.
- Treat other contributors with respect.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, or threats.
- Personal attacks, insults, or abusive language.
- Trolling or deliberately disruptive behavior.
- Publishing someone's private information without permission.
- Any other conduct that would be considered inappropriate in a professional environment.

## Reporting Issues

If you experience or witness unacceptable behavior, please report it privately to the project maintainers.

Please do not report security vulnerabilities through public GitHub issues. For security vulnerabilities, please follow the instructions in [SECURITY.md](SECURITY.md).

## Enforcement

Project maintainers will review reported incidents and take appropriate action when necessary.

Reports will be handled as confidentially as reasonably possible.

## Scope

This Code of Conduct applies to project repositories, issues, pull requests, discussions, and other project-related interactions.

## Attribution

This Code of Conduct is based on the Contributor Covenant.
